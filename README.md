
# AWS Cloud Monitoring and Alerting

## Project Overview
This project explains how to monitor AWS resources using Amazon CloudWatch and send alerts using Amazon SNS.

## Technologies Used
- AWS CloudWatch
- Amazon SNS
- Amazon EC2
- AWS IAM

## Key Features
- Monitor EC2 CPU utilization
- Create CloudWatch alarms
- Configure SNS email notifications
- Learn basic cloud monitoring and troubleshooting

## Learning Outcomes
- Understand AWS monitoring
- Learn alarm configuration
- Understand email alert notifications
